## 📌 Overview

This project is focused on building a strong foundation in **Data Analytics using SQL on Databricks**.
It demonstrates how structured data can be queried, transformed, and analyzed to extract meaningful insights.

---

## 🎯 Learning Goals

* Develop a solid understanding of **SQL fundamentals**
* Perform **data querying and filtering**
* Apply **aggregation and grouping techniques**
* Work with **relational datasets in Databricks**
* Build analytical thinking using real-world queries
